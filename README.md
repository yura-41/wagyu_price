# Git Lesson

## リモートリポジトリとローカルリポジトリとはそれぞれ何でしょうか？
リモートリポジトリは、サーバー上にあり共有して閲覧、書き換えが可能なもの。  
 ローカルリポジトリは、自分のpc上に保存されておりそれぞれが作成、書き換えが可能
## プッシュとマージの違いは何でしょうか？
プッシュはローカルからリモートに成内容を送信し複製ができる。  
マージは同じリポジトリ内で別ブランチに作成内容を上書きする。
## コミットとプッシュの違い
コミットは、作業内容をローカルに保存し何をしたか分かりやすく記録するもの.
## コミットのメッセージはどのように書いてあげるのが最適でしょうか？
完結に分かりやすく具体的な名称などを使う
## ローカルでマージするフローと、プルリクエストでマージするフローの違いは何でしょうか？
ローカルでは、全て一人で確認を行うため、間違いに気づきにくいが.  
プルリクエストは別の人に確認をお願いしてからマージされるため間違えに気づきやすい。
## コンフリクトを起こしてしまった場合、どう対処すべきですか？
どちらを取り込むべきか、もしくはどちらも取り入れるかをコードをかいた人同士やチームリーダーに相談して決める。  
取り込み作業が終わったら再度作業内容をコミットする。
